This U.S. Sales Dashboard provides a comprehensive overview of sales performance for a supermarket business, combining multiple visualizations to highlight key business insights. At the top, it displays important KPIs such as total sales ($21,300), total profit ($3,737), and profit percentage (21%), giving a quick snapshot of overall performance. The dashboard compares buying and selling values to evaluate profitability, while product-wise sales analysis identifies the best-performing products contributing to revenue. A sales type breakdown (Retail vs. Wholesale) helps understand which channel drives more business. The daily sales trend visualization shows how revenue fluctuates over time, making it easier to identify peak sales periods. Additionally, payment mode distribution (such as cash, card, or online) provides insights into customer preferences. Category-wise analysis highlights which product categories generate the highest sales. Overall, this dashboard effectively supports data-driven decision-making by presenting sales trends, customer behavior, and profitability in a clear and interactive manner.
